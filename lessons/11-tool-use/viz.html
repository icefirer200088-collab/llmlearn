llmlearn · Lesson 11

Tool Use：让模型调用外部工具

LLM 算不准大数乘法、不知道今天的天气、也没法帮你发邮件。但它可以说出"我需要调用某个工具，参数是什么"——由你的程序去执行，再把结果交还给它。模型负责决策，代码负责执行。

01一次完整的工具调用

选一个问题，然后点"下一步"。左边是对话的样子，右边是真正在 API 里来回传递的 messages。（这里的“模型”是用规则模拟的，为了能离线运行；tool_use.py --real 可以接真实的 Claude API。）

① 用户提问→② 模型决定调用工具→③ 你的代码执行工具→④ 结果返回给模型→⑤ 模型给出最终回答

API 中的 messages（JSON）


  






  
02工具是怎么"告诉"模型的？

  
每个工具用 名字 + 描述 + JSON Schema 定义参数。这些定义会被放进 prompt 里。模型在训练中学会了：需要时，输出一个特定格式的结构化调用。描述写得好不好，直接决定模型会不会在对的时候调用对的工具。
