Self-Attention：让每个 token 去"看"其他 token

第 01 课里每个 token 都拿到了一个向量，但它们互相不知道对方的存在。"苹果"在"吃苹果"和"苹果手机"里应该是不同的意思 —— Self-Attention 就是让每个 token 根据上下文更新自己的机制。

01注意力 = 一次"软"的查字典

普通字典：拿着 key 精确匹配，取出 一个 value。注意力：拿着 query 和所有 key 算相似度（点积），softmax 成权重，把 所有 value 按权重混合。转动下面的 query 方向，看权重如何变化。

query 方向
锐度（1/温度）

每个 key 的得分 q·k → softmax 权重

输出 = Σ 权重 × value（value 是一种颜色）

锐度调高 → 接近"硬"查字典（只取最像的那个）；调低 → 所有 value 平均。Transformer 里这个"锐度"由 1/√d 和向量本身的长度共同决定。

02完整走一遍 Self-Attention 计算

输入一句话（用空格分隔 token）。每个 token 的 embedding X 先分别乘三个矩阵得到 Q、K、V，然后 Attention(Q,K,V) = softmax(QKᵀ/√d) · V。点击任意一行，看这个 token 在"看"谁。

① X（embedding）

② Q = X·WQ

K = X·WK

V = X·WV

③ 打分 S = Q·Kᵀ （行 = query，列 = key）

④ A = softmax(S)，每行加起来 = 1

⑤ 输出 Z = A·V：每个 token 的新向量 = 它关注的 token 的 V 的加权平均

03为什么要除以 √d？

若 q、k 每一维都是均值 0 方差 1 的随机数，点积 q·k 的方差 = d。d 越大，分数越大，softmax 就越"尖"，梯度几乎为 0。下面随机生成 8 个 key，对比两种做法的 softmax 分布。
