03KV Cache：别重复计算已经算过的东西

生成第 t 个 token 时，注意力需要前面所有 token 的 K 和 V。但前面 token 的 K、V 不会变（因果掩码！）。不缓存的话，每一步都要把所有 token 的 K、V 从头算一遍；缓存之后，每步只算新 token 那一行。

0不缓存：累计计算 K/V 行数
0KV Cache：累计行数

不缓存（橙 = 本步重新计算）

有 KV Cache（蓝 = 从缓存读取，橙 = 新算）

生成 n 个 token：不缓存要算 1+2+…+n = n(n+1)/2 行，KV Cache 只要 n 行。n = 1000 时差 500 倍。代价是显存：要把每一层、每个 token 的 K 和 V 都存下来。

KV Cache 显存计算器

显存 = 2（K 和 V）× 层数 × KV 头数 × 每头维度 × 序列长度 × batch × 每个数的字节数
