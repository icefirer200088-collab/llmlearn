Prompt 与 In-Context Learning

从这一课开始，我们不再训练模型，而是用好模型。一个惊人的事实是：不改任何参数，只在输入里放几个例子，模型就能学会新任务 —— 这叫上下文学习（ICL）。它为什么能成立？Prompt 的每一部分又在起什么作用？

01拆开一个 Prompt

对模型来说，Prompt 就是一串 token，它要做的仍然只是"预测接下来最可能的内容"。每个组件都在改变这个"最可能"。勾选组件，看拼出来的完整输入。

02ICL 的一种机制：Induction Head（归纳头）

Anthropic 的可解释性研究发现，Transformer 里普遍存在一种两层配合的电路：前一 token 头先给每个位置记下"我前面是谁"；归纳头再在当前 token 上一次出现的地方找"它后面跟的是谁"，然后把那个 token 复制过来。也就是模式 [A][B] … [A] → [B]。点击任意一个 token，看归纳头会预测什么。

这个简单的"找到上次出现、复制后面的内容"的能力，让模型可以照着上下文里的例子的格式和映射关系往下写。研究发现归纳头在训练中某个时刻突然出现，同时模型的上下文学习能力也突然变强。真实模型的 ICL 远比这复杂（会做模糊匹配、抽象类比），但这是一个被清楚理解的起点。

03为什么"一步步想"有用？

模型生成每个 token 时做的计算量是固定的（同样多的层）。直接输出答案，相当于要求模型在 1 个 token 的计算里完成全部推理；让它先写出中间步骤，每一步都多了一整轮计算，并且之前的中间结果都在上下文里可以"回看"。
