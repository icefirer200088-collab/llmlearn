ReAct Agent：思考 → 行动 → 观察，循环往复

上一课的工具调用只有一来一回。Agent 就是把它放进一个循环：模型自己决定下一步做什么，看到结果后再决定下一步，直到任务完成。ReAct（Reason + Act）是最经典的框架 —— 简单到只有一个 while 循环。

01看一个 Agent 一步步完成任务

选一个任务，点"下一步"或"自动运行"。左侧是 Agent 循环当前所处的阶段，右侧是完整轨迹（全部会作为上下文喂给下一轮的模型）。轨迹是预先写好的示意脚本，工具结果是真实计算的。

循环轮数：0 / 上限 8　　工具调用：0 次

每一轮都要把全部历史重新发给模型 —— 轨迹越长越贵、越慢，这也是 Agent 需要“记忆管理”的原因（第 13 课）。

02Agent 的骨架代码

无论框架多复杂，核心都是这个循环。react_agent.py 里有可运行的完整版本（支持离线模拟和真实 Claude API）。

messages = [system_prompt(工具说明 + 输出格式), 用户任务]
for turn in range(MAX_TURNS):              # 一定要设上限，防止死循环
    reply = llm(messages, stop=["Observation:"])   # 让模型只写到“行动”为止
    messages.append(reply)
    if "Final Answer:" in reply:
        return 解析出的答案
    tool, args = parse_action(reply)       # 解析 Action: tool[args]
    try:
        obs = TOOLS[tool](args)
    except Exception as e:
        obs = f"错误：{e}"                  # 错误也是观察，让模型自己纠正
    messages.append(f"Observation: {obs}")
return "超过最大步数，任务未完成"
