文字是怎么变成数字的？

神经网络只认识数字。LLM 的第一步，是把文本切成一个个 token，给每个 token 一个编号，再用编号去一张大表里"查"出一个向量。本页三个实验，带你亲手走一遍。

01三种切法，各有代价

在下面输入任意文本（中英文都行），观察三种切分方式得到的 token 数量。BPE 一行使用的是 实验 02 里你训练出的合并规则 —— 去下面多点几次"合并"，再回来看看它的变化。

字符级：词表极小，但序列很长；单词级：序列短，但词表爆炸、遇到新词就 [UNK]；子词级（BPE）是折中——常见词是一个 token，罕见词拆成几块。

03Embedding：编号 → 向量，本质是查表

词表里每个 token 对应 Embedding 矩阵的一行。左边点任意一行（或在上方切分结果里看编号），就是模型"读到"这个 token 时拿到的向量。真实模型里这张表有 5 万~20 万行、几千列，并且会在训练中被不断更新。

Embedding 矩阵 E（词表大小 × 8 维）· 颜色 = 数值正负

训练后：意思相近的词，向量也相近

依次点击两个词，计算它们的余弦相似度。

余弦相似度 cos(a,b) = a·b / (|a||b|)：方向越一致越接近 1，正交为 0，相反为 −1。这里为了能画出来只用了 2 维，真实 embedding 是几千维，但"方向表示语义"的道理一样。
